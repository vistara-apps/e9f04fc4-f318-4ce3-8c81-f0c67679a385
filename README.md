# YieldSense - Intelligent BSC DeFi Yield Optimization

A production-ready Base Mini App for maximizing returns on Binance Smart Chain through automated vaults, risk-adjusted strategies, and tokenized liquidity positions.

## Features

- **Automated Yield Vaults**: Smart contracts that auto-compound rewards and optimize strategies
- **Risk-Adjusted Strategies**: Curated farming strategies with transparent risk scores
- **Impermanent Loss Mitigation**: Tools to predict and reduce IL exposure
- **Tokenized Liquidity Positions**: Convert LP tokens into tradable, collateralizable assets

## Tech Stack

- Next.js 15 with App Router
- React 19
- TypeScript
- Tailwind CSS
- OnchainKit (Coinbase)
- Farcaster MiniApp SDK
- Wagmi + Viem

## Getting Started

1. Install dependencies:
```bash
npm install
```

2. Run the development server:
```bash
npm run dev
```

3. Open [http://localhost:3000](http://localhost:3000)

## Theme

Uses COINBASE theme with:
- Dark navy background (#0a1929)
- Coinbase blue accents (#0052ff)
- Subtle rounded borders
- Glass morphism effects

## Production Build

```bash
npm run build
npm start
```
